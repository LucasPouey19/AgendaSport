# 9.2 Ferramentas de Colaboração

<!-- Como GitHub, Trello e Teams foram usados nesta aula -->

- **GitHub:** utilizado para armazenar o código-fonte do projeto, controlar versões, criar branches para diferentes funcionalidades e realizar Pull Requests para revisão e integração das alterações.

- **Trello:** utilizado para organizar as atividades do projeto através de um quadro Kanban, permitindo acompanhar as tarefas nas etapas **Backlog → A Fazer → Fazendo → Revisão → Concluído**.

- **Teams:** utilizado para comunicação entre os integrantes da equipe, realização de reuniões, registro de decisões e compartilhamento de links relacionados ao projeto e aos Pull Requests.

- **Figma:** utilizado para criação e organização dos protótipos das interfaces Web e Mobile, auxiliando na definição dos fluxos de navegação e componentes visuais.

# Integração entre as Ferramentas

As ferramentas utilizadas no desenvolvimento do Agenda Sport são integradas para organizar o planejamento, a comunicação, o desenvolvimento e o acompanhamento das atividades do projeto.

O **Trello** é utilizado para organizar as tarefas do projeto. As atividades são distribuídas no quadro Kanban, passando por etapas como Backlog, A Fazer, Fazendo, Revisão e Concluído.

Quando uma tarefa é iniciada, os integrantes utilizam o **Teams** para comunicação, alinhamento das atividades e tomada de decisões. O Teams também permite compartilhar informações, links, documentos e Pull Requests relacionados ao desenvolvimento.

Durante a implementação, o código é desenvolvido e versionado utilizando **Git e GitHub**. Cada funcionalidade pode ser desenvolvida em uma branch específica e, após sua conclusão, enviada para um **Pull Request**, permitindo a revisão pelos demais integrantes antes da integração ao projeto principal.

O **Figma** é utilizado para criar os protótipos das telas. Os protótipos servem como referência para os integrantes responsáveis pelo desenvolvimento do Front-end Web e Mobile.

Dessa forma, o fluxo de integração pode ser representado da seguinte maneira:

**Trello → Teams → Figma → Git/GitHub → Pull Request → Revisão → Código integrado**

Essa integração permite que a equipe tenha uma visão organizada das atividades, mantenha uma comunicação centralizada e tenha maior controle sobre as alterações realizadas no código durante o desenvolvimento do Agenda Sport.
