# 2.3 Acordos de Time

## Canais de Comunicação

- Canal de texto e equipe dentro do teams atualizando a cada mudança e ideia nova.

## Daily / Reuniões

- Reuniões semanais no teams para alinhar os trabalhos e comunicar novas ideias.

**## Padrão de Commits**

- Os commits são realizados pelo GitHub, mantendo uma descrição simples sobre a alteração realizada. 

**## Regras de Revisão de PR**

- As alterações realizadas no projeto são revisadas antes de serem implementadas à versão principal. A revisão verifica se a alteração está funcionando e se não prejudica outras partes do projeto. Sempre que necessário, o responsável pela alteração realiza os ajustes solicitados pelo time. Nós buscamos realizar as revisões durante as reuniões semanais ou assim que possível.
